# SpaceAboveTheTrees — Silo Server Plugin Repository

Community plugin repository for [Silo Server](https://siloserver.org). Add this repository once in Silo Server to browse, install, and receive automatic updates for all plugins maintained here.

---

## Quick Setup

1. Open your **Silo Server** web interface and navigate to **Admin → Integrations → Plugins → Repositories**.
2. Add the repository URL:
```text
https://raw.githubusercontent.com/spaceabovethetrees/silo-plugins/main/repository.json
```
3. Browse the catalog and install the plugins you want to use.

## Transparency & Support

* **Pre-Release Software:** These are community-developed plugins built for Silo Server (which is currently pre-release software). Always maintain regular backups and use plugins at your own risk.
* **Open Source:** All plugin source code is open for inspection in each linked repository.
* **Bug Reports & Feature Requests:** Please submit feedback through the built-in reporting tool inside the respective plugin UI or open an issue in the plugin's GitHub repository.
